# GitHub Pages publication

The CV hero and Hugo blog publish together from `docs/` on `main`.

In repository Settings > Pages, select **Deploy from a branch**, branch **main**, folder **/docs**.

Build and publish with the [local publishing script](../development/local-publishing.md). There is no repository deployment Action. GitHub must still process the pushed branch before the update is live.

The public CV is at https://antoineboucher.info/CV/ and the blog at https://antoineboucher.info/CV/blog/.
