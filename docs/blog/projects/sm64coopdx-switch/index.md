**sm64coopdx-switch** ports [coop-deluxe/sm64coopdx](https://github.com/coop-deluxe/sm64coopdx) to **Nintendo Switch** homebrew. This fork tracks my Switch build work; stars on **this repo** are separate from upstream sm64coopdx (~1300★).

Blog write-up: [Handheld streaming and homebrew](https://antoineboucher.info/CV/blog/posts/handheld-streaming-homebrew/).

## Legal

You must provide your own **legally obtained Super Mario 64 ROM**. The repository contains port source and build scripts only — no game assets are distributed.

## Stack

- C homebrew port from sm64coopdx decomp/coop codebase
- Online co-op, Lua mod support (inherited from upstream)

See [README](https://github.com/antoinebou12/sm64coopdx-switch) for toolchain setup, ROM placement, and `.nro` build output.
