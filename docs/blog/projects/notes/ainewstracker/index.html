AINewsTracker collects financial news, analyses article text and exposes the resulting data through FastAPI. A separate strategy path uses stored information for historical backtests.

Source code · Published documentation · Interactive GitDiagram · Français

1. Overview

app/main.py assembles the service, registers the route groups and configures Redis caching. News processing moves through a service, text metrics and the article repository before reaching MongoDB.

The companion article, Following financial news through AINewsTracker, follows that path from an incoming feed to a stored article.

2. Getting started

cp .env.example .env
pip install poetry
poetry shell
poetry install
poetry run pytest
poetry run uvicorn app.main:app --reload

FastAPI documentation is available at http://localhost:8000/api/v1/docs according to the project guide. Docker users can start the documented stack with:

docker-compose up --build

3. Repository guide

  • app/main.py creates the application, registers routers and configures caching.
  • app/routers/ defines news, article, company, user, seed and strategy endpoints.
  • app/core/services/ contains news processing and text metrics.
  • app/core/repo/ contains persistence operations grouped by domain.
  • app/models/ defines records accepted and returned by the service.
  • app/seed/ loads company and news data from external sources.
  • app/core/trading/strategy.py handles strategy requests.

4. Features

  • ingest news through RSS, GNews and configured feeds;
  • analyse sentiment, topics and ticker allocation;
  • manage article, company, news and user records;
  • seed company and news data;
  • execute strategy requests for one or more companies;
  • run through Poetry or Docker Compose.

6. API contract

AreaDocumented operations
NewsCreate and read news; fetch RSS, GNews and feed entries
ArticlesCreate, list, read and delete articles; read an article score
CompaniesCreate companies, list companies and find one by ticker
StrategiesExecute a strategy for one company or a submitted company list

The running FastAPI OpenAPI document is the authority for exact request and response schemas.

7. Deployment

The repository includes a root Dockerfile, a development docker-compose.yml and a separate deploy/ directory. Compose dependency ordering is a startup order, not a readiness guarantee.

9. Limits

  • Sentiment and topic labels are analytical inputs, not financial advice or proof of causation.
  • Historical backtests do not guarantee future performance.
  • External feeds and market APIs have their own credentials, availability and usage terms.
  • Endpoint details can change; current source and OpenAPI take precedence.

11. Glossary

Repository

The versioned source files, configuration, and history of a project.

README

The repository’s entry document, usually covering its purpose and initial setup.

Dependency

A library, tool, or service that another component needs to build or run.

API

An interface through which software components exchange requests and results. An API does not have to use HTTP.

HTTP

A request-and-response protocol used by browsers and web services. A method, path, headers, and optional body describe a request.

Session

State kept across related requests, often to track a signed-in user. Authentication and permission checks remain separate concerns.

Container

An isolated process environment created from an image. Persistent data needs storage outside the container’s disposable filesystem.

Docker Compose

A configuration format and tool for starting related containers, networks, and volumes. Startup order alone does not guarantee service readiness.

Published port

A host port mapped to a service’s container port. Publishing a port can expose that service beyond its container network.

CLI

A text interface in which commands and arguments select operations. Exit codes let scripts detect success or failure.

Build

The steps that turn source files and dependencies into a runnable program or distributable artifact.

Mermaid

A text-based diagram language. Nodes and connections describe a model; the diagram itself does not execute the project.

Backend

An implementation behind a shared interface. Depending on context, it can mean a server-side service or a graphics, input, or storage implementation.

Database

A system for storing and querying structured records. Its schema, access rules, and persistence determine how the application can use that data.
