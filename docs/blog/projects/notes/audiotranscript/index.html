AudioTranscript: From WAV chunks to transcription

AudioTranscript breaks a WAV recording into chunks around silence, sends each chunk to a recognition service and concatenates the results. The current implementation uses Amazon recognition, even though its docstrings still mention Google.

AudioTranscript: cutting audio at the silences · 0:55 · AI-written script, synthetic voices

Transcript

Ava: How do you turn a long recording into text when a recognition service only wants small pieces?

Andrew: Cut it up, I guess?

Ava: Yes, but where you cut matters. AudioTranscript takes a WAV file and finds the silences. It breaks the recording into chunks around those quiet moments, so it doesn't slice through the middle of a word.

Andrew: Then what?

Ava: Each chunk goes to a speech recognition service, and the pieces of text come back and are joined into one transcript. The current version uses Amazon's recognition service.

Andrew: How big is the project?

Ava: Small and focused. It's pure Python, MIT licensed, and Antoine's note describes it as an audio ingestion and transcription pipeline with timestamp alignment.

Andrew: So the idea is one clean pipeline.

Ava: Right: split at silence, recognize, stitch back together. The written page has the details.

2. Use cases

Python CLI that splits a WAV file on silence and transcribes each chunk into a single text.

Split audio on silence
CLI user

main.py loads the WAV with pydub and calls split_on_silence with --min-silence-len, --silence-thresh (relative to the file’s dBFS) and --keep-silence, writing each piece to audio-chunks/chunkN.wav.

Transcribe the chunks
CLI userAmazon Transcribe

Each chunk goes to recognize_amazon (us-east-1, S3 bucket from .env) and the texts are joined and printed. The README describes Google Speech Recognition, but the code calls Amazon; the --language option is not passed on.

Set AWS keys in .env
CLI userAmazon Transcribe

load_dotenv reads AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY and AWS_BUCKET_NAME; main.py raises an error if one is missing.

Try Whisper on a sample
CLI userHugging Face Hub

ai.py is a separate script that loads openai/whisper-large-v2 with transformers and transcribes one LibriSpeech dummy sample; it is not wired to the CLI and its packages are not in requirements.txt.

2.1. Scenario: Transcribe a recorded interview

  1. Run pip install -r requirements.txt, plus python-dotenv, which main.py imports but the file does not list.
  2. Create a .env file with AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY and AWS_BUCKET_NAME.
  3. Run python main.py interview.wav -m 700 -s -16 (the path is positional and defaults to caro.wav).
  4. main.py writes the chunks to audio-chunks/ and shows a Rich progress bar.
  5. Each chunk is sent to Amazon Transcribe and the full text is printed at the end.

5. Features and components 2

Audio segmentation
main.py loads a WAV through pydub and calls split_on_silence. The threshold is calculated relative to the recording’s dBFS level. Each chunk is exported to audio-chunks before recognition.
Recognition and output
A SpeechRecognition Recognizer reads each exported file and calls recognize_amazon. The loop appends the returned text to whole_text, which is printed and returned. Typer exposes the file and segmentation parameters.
