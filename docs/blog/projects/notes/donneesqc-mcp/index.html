donneesqc-mcp: An MCP gateway to public data

donneesqc-mcp is a fork exposing Québec and Montréal open-data operations through MCP tools. Its entry point registers the tool collection and starts an HTTP transport, leaving dataset access and geographic helpers in separate modules.

1. Overview

1.1. Why it exists

Production MCP server connecting AI assistants to Quebec & Montreal open data APIs with strict schema validation.

1.2. Best fit

Natural language querying of public municipal and provincial datasets across transportation, demographics, and municipal services.

4. Features and components 2

Server bootstrap
main.py configures logging, optionally initializes Sentry, calls register_all_tools and runs the MCP object with streamable-http. Monitoring is optional; it is not the mechanism that serves dataset queries.
Data-service boundary
The documented tool groups cover catalog discovery, CKAN DataStore access, resource downloads and geographic enrichment. A catalog result describes a resource; the actual table or file is a separate request and may use a different format.

12. Glossary

Repository

The versioned source files, configuration, and history of a project.

README

The repository’s entry document, usually covering its purpose and initial setup.

Dependency

A library, tool, or service that another component needs to build or run.

HTTP

A request-and-response protocol used by browsers and web services. A method, path, headers, and optional body describe a request.

Container

An isolated process environment created from an image. Persistent data needs storage outside the container’s disposable filesystem.

Published port

A host port mapped to a service’s container port. Publishing a port can expose that service beyond its container network.

CLI

A text interface in which commands and arguments select operations. Exit codes let scripts detect success or failure.

MCP

Model Context Protocol: a protocol through which an AI client discovers and calls tools and reads resources from a server.

Fork

A separate repository derived from another project. A change in a fork is not automatically a change in the upstream project.
