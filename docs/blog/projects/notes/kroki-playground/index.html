kroki-playground: An editor, an API and a renderer

kroki-playground is a Next.js interface for editing text diagrams and previewing their output. Its server route validates the requested diagram type and format, encodes the source and fetches the rendered result from Kroki.

Features and components 2

Validation before rendering
app/api/generate-diagram/route.ts accepts GET and POST inputs through a shared validator. encodeDiagramPayload prepares the source for the Kroki URL. KROKI_BASE_URL selects the server-side rendering endpoint.
Response and failure states
The route reads the returned bytes and responds with diagramUrl, base64 diagramData and mimeType. A non-success response from Kroki becomes a 502 with an upstream error code, distinct from invalid input.

Diagram HTTP API

The route file defines GET and POST /api/generate-diagram. POST reads JSON; GET reads the same fields from query parameters. The handler validates the diagram type and format, compresses UTF-8 source with DEFLATE, encodes it for a URL and fetches the selected Kroki renderer.

Request example
POST /api/generate-diagram
Content-Type: application/json

{
  "selectedDiagram": "mermaid",
  "diagramSource": "flowchart LR\n  Client --> Server",
  "outputFormat": "svg"
}

Response and errors

A successful JSON response contains diagramUrl, diagramData (base64 bytes) and mimeType. Decode diagramData using mimeType when displaying the result. This is not a raw SVG response.
HTTP 400 covers MISSING_DIAGRAM_TYPE, INVALID_DIAGRAM_TYPE, SOURCE_TOO_LARGE and INVALID_OUTPUT_FORMAT. A Kroki HTTP failure becomes 502 KROKI_UPSTREAM_ERROR with upstreamStatus; a thrown request or decoding error becomes 500 INTERNAL_ERROR. For a 502, inspect the selected format and Kroki response before retrying. Test with a small graph against a local deployment.
Authentication, limits and pagination

The inspected route has no authentication, pagination or rate limiter. A deployment proxy may impose its own rules. The source limit is 512,000 characters. KROKI_BASE_URL configures server requests; NEXT_PUBLIC_KROKI_BASE_URL configures browser previews. The README mentions /api/generateDiagram, while this source file defines the hyphenated route.
