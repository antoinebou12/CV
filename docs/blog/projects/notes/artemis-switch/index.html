Artemis-Switch: A streamed frame from host to screen

Artemis-Switch is a fork in the Moonlight streaming family. The host runs the game; the client receives compressed video and audio while sending controller input back. Rendering a frame is only one part of that round trip.

Overview

Why it exists

Hardware-accelerated GameStream/Moonlight client in C++ with custom NVN display frame pacing for zero-stutter video.

Best fit

Ultra-low latency PC game streaming directly to Nintendo Switch handheld mode.

Features and components 2

Session and interface
The Borealis interface handles host selection and settings. MoonlightSession coordinates streaming, while the Switch decoder-and-render provider chooses concrete video and audio implementations. UI state and media processing have different lifecycles.
Platform-specific output
The provider constructs FFmpegVideoDecoder. With BOREALIS_USE_DEKO3D it selects ArtemisDKVideoRenderer, while other build flags select other renderers. Switch audio uses AudrenAudioRenderer. These are explicit build-time choices.
