## Where it connects to my projects

The Model Context Protocol material is the same protocol behind [uml-mcp](https://antoineboucher.info/CV/blog/posts/uml-mcp/), the MCP server that renders Mermaid, PlantUML and Kroki diagrams from a chat client. The API course covers the request shape, tool use and streaming that an MCP client relies on.
