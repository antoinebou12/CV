- Author: Antoine Boucher (https://antoineboucher.info/CV/index-en.html)The diagram tool reached **25k uses** on the GPT Store. At school, UML is how we share an idea, and I built the tool so I would stop dragging boxes and arrows in Lucidchart.

![UML diagram generated via MCP in chat](https://antoineboucher.info/CV/blog/posts/gpt-store-diagram-tool/images/uml-mcp-chat.png)
