switch-wifi : Séparer les mesures réseau de l’interface

switch-wifi est un tableau de bord réseau pour Switch avec une interface Borealis. Il sépare les calculs portables de l’application console pour permettre de tester le cœur sans la chaîne de compilation Switch.

1. Aperçu

1.1. Pourquoi il existe

Utilitaire C++ natif communiquant directement avec les services wlan de l'OS Switch.

1.2. Cas d’usage

Configuration réseau rapide pour console Switch sans interface complexe.

2. Cas d’utilisation

Application homebrew pour Nintendo Switch qui affiche l'état du Wi-Fi, mesure le lien HTTPS et lit l'état Bluetooth.

Vérifier le lien Wi-Fi
Joueur sur SwitchHorizon NIFM / BTM

L'onglet Dashboard lit le type de lien, le SSID, l'IPv4, la passerelle, le DNS et les barres de signal 0 à 3 via NIFM (NetworkService) ; le RSSI vient de wlan:inf seulement si le micrologiciel l'expose.

Mesurer la connexion
Joueur sur SwitchServeur de débit HTTPS

SpeedTestEngine lance 8 sondes de latence HTTPS, puis un téléchargement de 25 Mio et un envoi de 10 Mio remplis de zéros avec libcurl vers speed.cloudflare.com par défaut, avec médiane, P95 et gigue.

Voir les réseaux enregistrés
Joueur sur SwitchHorizon NIFM / BTM

L'onglet Networks montre les métadonnées de base des profils enregistrés et les canaux autorisés par Horizon, avec le calcul de chevauchement de core/metrics ; les identifiants ne sont jamais affichés.

Inspecter le Bluetooth
Joueur sur SwitchHorizon NIFM / BTM

BluetoothService lit l'état radio BTM et le nombre d'appareils, puis lance un balayage BLE passif limité qui renvoie au plus dix adresses uniques.

Exporter un rapport
Joueur sur Switch

L'onglet About écrit sdmc:/switch-wifi-diagnostics.txt avec la version, la cible de compatibilité, les détails réseau et les compteurs Bluetooth, sans identifiants.

2.1. Scénario : Comparer deux canaux de routeur sur Switch

  1. Compiler build-switch/switch-wifi.nro dans le conteneur devkitpro/devkita64 et le vérifier avec python3 scripts/verify_nro.py.
  2. Copier le NRO sur la carte SD et le lancer depuis le menu homebrew.
  3. Ouvrir l'onglet Dashboard pour confirmer que la Switch est en Wi-Fi et noter les barres de signal.
  4. Lancer l'onglet Benchmark et lire la latence médiane, le P95, la gigue et les débits descendant et montant.
  5. Changer le canal du routeur, relancer la mesure et comparer les graphiques d'historique.
  6. Exporter sdmc:/switch-wifi-diagnostics.txt depuis l'onglet About pour garder le résultat.

4.2. Wi-Fi environment

README.md

  • Basic saved-network metadata without requesting full saved credential profiles.
  • Authentication/encryption labels.
  • Horizon allowed-channel query on HOS 6.0.0+.
  • 2.4 GHz and 5 GHz channel/frequency helpers.
  • Tested channel-overlap and contention-proxy math.
  • Nearby AP scan kept behind a hardware-verification boundary until opaque Horizon AP records can be decoded safely across firmware versions.
  • RF noise floor and SNR shown as unavailable rather than inferred from unrelated values.

4.4. Development rules

CONTRIBUTING.md

  • Keep Horizon/libnx IPC out of the Borealis UI layer.
  • Add a host-side test for calculations and parsers whenever possible.
  • Gate firmware-dependent behavior explicitly.
  • Do not add code that retrieves Wi-Fi passphrases just to display profile information.
  • Do not call a derived AP-overlap value "noise floor", "SNR", or "channel utilization" unless the underlying metric is actually measured.
  • Keep Bluetooth diagnostics read-only.

5. Fonctions et composants 2

Cœur de calcul portable
CMake construit switch_wifi_core depuis src/core/metrics.cpp. Les tests hôtes utilisent cette bibliothèque indépendamment de Borealis. Ils couvrent les métriques, l’historique et les benchmarks, avec des sanitizers optionnels.
Intégration console
La cible applicative rassemble les modules src et lie Borealis, les bibliothèques libnx et libcurl. Le réseau et l’interface dépendent donc de la plateforme, tandis que le cœur numérique peut rester indépendant.

11. Limites et points à vérifier

Une valeur radio inaccessible doit rester indisponible, sans devenir zéro. La configuration de compilation ne prouve pas la compatibilité ou la précision sur chaque firmware.

13. Glossaire

Dépôt

Les fichiers source, la configuration et l’historique versionné d’un projet.

README

Le document d’entrée du dépôt, qui présente généralement son rôle et son installation.

Dépendance

Une bibliothèque, un outil ou un service nécessaire à la compilation ou à l’exécution d’un composant.

HTTP

Un protocole de requête et réponse utilisé par les navigateurs et services web. Une requête comprend une méthode, un chemin, des en-têtes et parfois un corps.

Port publié

Un port de l’hôte associé au port d’un service dans un conteneur. Sa publication peut rendre le service accessible hors du réseau des conteneurs.

Compilation

Les étapes qui transforment les sources et dépendances en programme exécutable ou en livrable distribuable.
