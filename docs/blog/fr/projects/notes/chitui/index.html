ChitUI : Une passerelle locale vers les imprimantes résine

ChitUI fournit une interface web pour des imprimantes résine SDCP. Un processus Python sert les ressources web, découvre les imprimantes sur le réseau local et traduit les actions du navigateur en communications avec les machines.

8. API de transfert vers l’imprimante

POST /upload accepte les champs multipart file et printer. L’identifiant sélectionne une entrée du dictionnaire des imprimantes découvertes. Les extensions acceptées sont ctb, goo et prz. Le serveur crée un fichier temporaire et transfère des blocs au point d’accès de l’imprimante sur le port 3030.

Contrôles d’accès lus dans les gestionnaires. Une mention « admin » dans le README ne figure ici que si le code la vérifie.
MéthodeCheminContrôle vérifiéFichier
POST/uploadAucun contrôle d’authentification dans le gestionnaire inspecté. Les champs multipart file et printer sont requis.main.py
GET/uploadAucun contrôle d’authentification. Le gestionnaire inspecté retourne 405.main.py
GET/progressAucun contrôle d’authentification dans le gestionnaire inspecté. La réponse est un text/event-stream partagé entre les transferts.main.py
Exemple de requête
POST /upload
Content-Type: multipart/form-data

file: [supported print file]
printer: [identifier returned by discovery]

8.1. Réponse et erreurs

Le corps de succès est {“upload”:“success”,“msg”:“File uploaded”}. Un fichier ou une imprimante manquants et une extension non prise en charge retournent 400. GET /upload retourne 405. GET /progress diffuse des mises à jour text/event-stream.
Vérifiez le fichier sur l’imprimante après le transfert. Le helper met la progression à 100 et retourne true même lorsqu’un bloc échoue et interrompt la boucle. La réponse de succès ne prouve donc pas la livraison. Le calcul divise aussi par le nombre de blocs complets de 1 Mio, qui vaut zéro pour un fichier plus petit.
Authentification, limites et pagination

Les gestionnaires inspectés n’ont ni authentification ni limiteur de débit. Gardez cette interface sur un réseau de confiance. La progression est globale et ne distingue pas les transferts simultanés. La pagination ne s’applique pas à cette opération.

13. Glossaire

Dépôt

Les fichiers source, la configuration et l’historique versionné d’un projet.

README

Le document d’entrée du dépôt, qui présente généralement son rôle et son installation.

Dépendance

Une bibliothèque, un outil ou un service nécessaire à la compilation ou à l’exécution d’un composant.

HTTP

Un protocole de requête et réponse utilisé par les navigateurs et services web. Une requête comprend une méthode, un chemin, des en-têtes et parfois un corps.

Session

Un état conservé entre plusieurs requêtes, souvent pour suivre un utilisateur connecté. L’authentification et les permissions restent des vérifications distinctes.

Conteneur

Un environnement de processus isolé créé à partir d’une image. Les données persistantes nécessitent un stockage hors de son système de fichiers temporaire.

Port publié

Un port de l’hôte associé au port d’un service dans un conteneur. Sa publication peut rendre le service accessible hors du réseau des conteneurs.

Interface en ligne de commande

Une interface textuelle où les commandes et arguments choisissent les opérations. Les codes de retour permettent aux scripts de détecter un succès ou un échec.

Compilation

Les étapes qui transforment les sources et dépendances en programme exécutable ou en livrable distribuable.
