TCH099 : Un routeur PHP pour les pages et l’API

TCH099 est un projet pédagogique qui combine pages frontend statiques et API PHP. Les routes exposent la frontière: certains chemins retournent du HTML, tandis que d’autres appellent des scripts serveur.

Suivre un parcours dans le code

Comparez GET /login et POST /api/login. Le premier choisit une page; le second lance l’authentification. Les contrôles doivent protéger les opérations API autant que la page administrative.

API HTTP et permissions

routes.php associe les chemins ci-dessous. Le README montre des chemins comme /api/login.php et des messages en français. Les gestionnaires utilisent les chemins de ce tableau et des messages en anglais. La colonne d’accès indique un contrôle trouvé dans le gestionnaire.

Réponse et erreurs

  • Succès : api/login.php retourne status: success, message: Login successful et redirect: /home.
  • Identifiants invalides : le corps JSON contient status: error et Invalid username or password.
  • Autres méthodes HTTP : le corps JSON contient Invalid request method.
  • Langue des messages : le gestionnaire utilise l’anglais, tandis que les exemples du README sont en français.
  • Détails de session : GET /api/user_details exige user_loggedin et retourne user_details depuis la session.
  • Liste des clients : GET /api/clients exige aussi le rôle admin. Sa requête SELECT * FROM Clients inclut la colonne du mot de passe dans une réponse réussie.
  • Démonstrations publiques : les requêtes GET et POST vers /api/hello-world/$langue et /api/random-image n’ont pas de contrôle de session. Hello World utilise le nom de session pour prenom lorsqu’il existe.
  • Image aléatoire : imageType: human retourne l’URL thispersondoesnotexist.com. Toute autre valeur appelle The Cat API.
Authentification, limites et pagination

POST /api/signup accepte le rôle admin ou client dans le JSON. signup.php n’exige pas une session administrateur avant d’enregistrer ce rôle. router.php envoie Access-Control-Allow-Origin: *. Ces gestionnaires ne fixent pas de limite de débit. GET /admin est une page: routes.php appelle isAdmin() et inclut sinon 403.html. La connexion ne définit pas de statut HTTP d’erreur; l’échec reste dans le JSON.
