2. Cas d’utilisation

README de profil GitHub avec liens, badges, projets épinglés et statistiques, tenu à jour par des Actions planifiées.

Lire le profil et les liens
Visiteur du profil

README.md commence par le titre plateforme et infographie, puis les liens (GitHub, LinkedIn, site, CV, courriel), les badges de certification et les principaux langages et outils.

Parcourir les projets phares
Visiteur du profil

Une section repliable Featured projects affiche des cartes pour des dépôts comme AINewsTracker, hass_renpho, ipc-toolkit et TrueMapData, ainsi que les organisations DashCTRL, ETSim et UFOKEK.

Régénérer le graphe 3D
GitHub Actions

github-profile-3d-contrib.yml s’exécute chaque jour à 5 h UTC, génère le calendrier 3D des contributions, ne garde que profile-night-green.svg et le valide dans le dépôt.

Actualiser badges LeetCode
GitHub Actions

update-readme.yml s’exécute chaque jour à 12 h UTC, récupère les statistiques sur leetcodestats.cyclic.app et réécrit les badges entre les marqueurs LEETCODE_STATS de README.md.

Vérifier les liens
Propriétaire du profilGitHub Actions

À chaque push ou pull request vers main ou master, check-links.yml lance lychee sur README.md et docs/**/*.md et écrit un résumé de tâche.

Publier la page Jekyll
Propriétaire du profilGitHub Actions

jekyll-pages.yml construit docs/ avec le thème jekyll-theme-primer et le déploie sur GitHub Pages ; docs/index.md renvoie au README du profil.

2.1. Scénario : Modifier le profil et laisser l’automatisation suivre

  1. Le propriétaire modifie README.md, par exemple la liste Featured projects, et pousse sur master.
  2. check-links.yml lance lychee sur README.md et le Markdown de docs et signale les liens brisés.
  3. jekyll-pages.yml construit docs/ et déploie le petit site Jekyll sur GitHub Pages.
  4. Chaque jour, github-profile-3d-contrib.yml régénère profile-night-green.svg et le valide.
  5. Un visiteur ouvre la page de profil et voit le README à jour, les cartes de statistiques et le calendrier 3D.

5. Fonctions et composants 2

README et ressources
README.md est le document visible du profil. Les dossiers images, models et profile-3d-contrib regroupent des ressources associées. GitHub affiche le document, tandis que certains services liés produisent leurs propres images.
Modifications planifiées
Le workflow update-readme récupère des statistiques LeetCode, construit des liens de badges et remplace le texte entre des marqueurs du README. D’autres workflows concernent le graphique de contributions, les liens et Pages.

Ce que couvre l’analyse

Les dossiers connus de dépendances et de compilation, les fichiers d’identifiants et les binaires sont exclus. La collecte couvre les README, les manifestes reconnus et les fichiers source pris en charge.

Les statistiques Linguist couvrent l’ensemble du dépôt et peuvent inclure d’autres langages.

9. Limites et points à vérifier

Les services de badges peuvent tomber en panne ou devenir périmés. Un graphique de profil présente les données d’une source, sans mesurer indépendamment la qualité des contributions.

11. Glossaire

Dépôt

Les fichiers source, la configuration et l’historique versionné d’un projet.

README

Le document d’entrée du dépôt, qui présente généralement son rôle et son installation.

Dépendance

Une bibliothèque, un outil ou un service nécessaire à la compilation ou à l’exécution d’un composant.

HTTP

Un protocole de requête et réponse utilisé par les navigateurs et services web. Une requête comprend une méthode, un chemin, des en-têtes et parfois un corps.

Compilation

Les étapes qui transforment les sources et dépendances en programme exécutable ou en livrable distribuable.

Intégration continue

Des vérifications automatiques lors des changements de source, comme la compilation, les tests et l’analyse statique. Elles ne couvrent que ce qu’elles vérifient.

GPU

Un processeur conçu pour les calculs parallèles, dont le rendu graphique et de nombreuses opérations numériques.

Maillage

Une surface représentée par des sommets et des éléments reliés, souvent des triangles. Sa géométrie est distincte de son matériau ou de sa texture.
