novatorem : Des données musicales à un widget SVG

Ce fork novatorem produit des widgets musicaux depuis des services externes. Un orchestrateur Flask gère le rendu; Spotify et Last.fm ont des modules distincts. La pochette fournit une image et des couleurs au SVG.

Transcription

Sylvie : Imagine un profil GitHub qui affiche la chanson en cours, avec des couleurs assorties.

Thierry : C'est novatorem, et Antoine en maintient un fork. Il fabrique un widget de statut musical en image SVG, à intégrer dans un README.

Sylvie : D'où viennent les données musicales ?

Thierry : De Spotify ou de Last.fm. Chacun a son module, et une petite application Flask choisit la source et gère le rendu.

Sylvie : Et les couleurs ?

Thierry : La pochette fait double emploi. Elle est affichée dans le widget, et ses couleurs servent à styliser le SVG, donc la carte s'accorde à la pochette.

Sylvie : Donc ça se met à jour pendant qu'on écoute.

Thierry : Oui, c'est un statut d'écoute en direct. Surtout du Python avec des modèles Jinja, et l'auteur d'origine est cité. La page en dit plus.

2. Cas d’utilisation

Service Flask qui génère une carte SVG « en écoute » depuis Spotify ou Last.fm pour un README de profil GitHub.

Afficher le titre en écoute
Propriétaire du profilAPI Web Spotify

La route générique de api/orchestrator.py lit le morceau en cours, tire les couleurs de la pochette et renvoie une carte image/svg+xml ; vercel.json y associe /api/spotify.

Personnaliser les couleurs
Propriétaire du profil

Les paramètres background_color, border_color, background_type, show_status et compact sont validés dans api/config.py avant le rendu du gabarit Jinja2 choisi dans api/templates.json.

Utiliser Last.fm comme source
Propriétaire du profilAPI Last.fm

Si seuls LAST_FM_API_KEY et LAST_FM_USERNAME sont définis, ou si l’authentification Spotify échoue, get_now_playing passe à api/lastfm.py, qui peut chercher la pochette sur Deezer.

Ouvrir le morceau en cours
Propriétaire du profilAPI Web Spotify

GET /redirect envoie le visiteur vers l’URL du morceau, ou vers le dépôt d’origine si rien ne joue.

Renouveler le jeton Spotify
Propriétaire du profilAPI Web Spotify

scripts/spotify_local_auth.py capte le code OAuth sur http://127.0.0.1:8000/callback et écrit un nouveau jeton, avec option --update-vercel pour le pousser vers Vercel.

Prévisualiser en local
Propriétaire du profil

python start.py crée .venv, installe les dépendances, lance Flask sur le port 5000 et ouvre /preview ; docker-compose.yml exécute la même application avec une vérification /health.

2.1. Scénario : Ajouter une carte Spotify à un profil GitHub

  1. Créer une application Spotify avec l’URI de redirection http://127.0.0.1:8000/callback.
  2. Copier .env.example vers .env et remplir SPOTIFY_CLIENT_ID et SPOTIFY_SECRET_ID.
  3. Lancer python scripts/spotify_local_auth.py pour obtenir SPOTIFY_REFRESH_TOKEN.
  4. Lancer python start.py et vérifier la carte sur http://127.0.0.1:5000/preview.
  5. Déployer sur Vercel et intégrer <déploiement>/api/spotify comme image liée à /redirect dans le README du profil.

6. Fonctions et composants 2

Fournisseur et présentation
api/orchestrator.py contient Flask et les fonctions de rendu. Les modules des fournisseurs sont à côté. La configuration pilote modèles et palettes, séparant l’accès propre au service de l’apparence du SVG.
Traitement de la pochette
ImageData récupère la pochette une fois par objet et réutilise les octets pour le base64 et les palettes ColorThief. load_image_with_fallback essaie l’image, un remplacement, puis des couleurs par défaut en cas d’échec.

13. Glossaire

Dépôt

Les fichiers source, la configuration et l’historique versionné d’un projet.

README

Le document d’entrée du dépôt, qui présente généralement son rôle et son installation.

Dépendance

Une bibliothèque, un outil ou un service nécessaire à la compilation ou à l’exécution d’un composant.

API

Une interface par laquelle des composants logiciels échangent des requêtes et des résultats. Une API n’utilise pas nécessairement HTTP.

Conteneur

Un environnement de processus isolé créé à partir d’une image. Les données persistantes nécessitent un stockage hors de son système de fichiers temporaire.

Volume et montage de dossier

Un volume est un stockage géré par la plateforme de conteneurs ; un montage de dossier expose un chemin de l’hôte dans un conteneur.

Port publié

Un port de l’hôte associé au port d’un service dans un conteneur. Sa publication peut rendre le service accessible hors du réseau des conteneurs.

Compilation

Les étapes qui transforment les sources et dépendances en programme exécutable ou en livrable distribuable.

GPU

Un processeur conçu pour les calculs parallèles, dont le rendu graphique et de nombreuses opérations numériques.

Fork

Un dépôt distinct dérivé d’un autre projet. Une modification du fork ne devient pas automatiquement une modification du projet amont.
