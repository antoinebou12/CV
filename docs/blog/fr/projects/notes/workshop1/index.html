Workshop1

Workshop1 est un atelier Python d’AlgoÉTS construit autour de notebooks. La progression part de l’installation, passe par les appels API, pandas et la visualisation, puis se termine par un exercice d’EMA sur le cours d’Apple. Les faits ci-dessous viennent du dépôt, lu pour l’article associé.

  • Mis à jour 2026-10-24
Code sourceREADMEMarkdown

1. Aperçu

Pourquoi il existe. Un atelier d’initiation où chaque notion a une suite : une requête devient un tableau, le tableau devient un graphique.

Cas d’usage. Premier contact avec Python pour des étudiants en finance, avant de passer à une expérience par lots comme BatchBacktesting.

2. Cas d’utilisation

Atelier AlgoÉTS en français : carnets Jupyter, des bases de Python aux API, à pandas, aux graphiques et à une EMA sur Apple.

Préparer son environnement
ParticipantJupyter ou Colab

0.1_python_environement présente virtualenv, Anaconda et Jupyter Lab ; 0.2_jupyter_cloud montre DeepNote et Google Colab, et le README pointe vers une copie Colab du premier carnet.

Apprendre les bases de Python
ParticipantJupyter ou Colab

1.1_python_basic et 1.2_python_advanced couvrent variables, structures de contrôle, lecture de fichier (monfichier.txt) et une petite base SQLite (ma_base.db).

Appeler une API web
ParticipantJupyter ou Colab

2.1_python_api explique les verbes REST, les codes d'état, les jetons Bearer, les clés d'API et OAuth, avec des exemples requests et httpx asynchrone.

Nettoyer des données (pandas)
Participant

3.1_python_panda présente les DataFrame, le filtrage avec loc et iloc, les valeurs manquantes, les fusions, les indicateurs pandas_ta et une comparaison avec polars.

Tracer une EMA sur Apple
ParticipantAPI de cours FMP

5.1_project_ema récupère les cours journaliers d'AAPL via historical-price-full de FMP, calcule une EMA 20 jours avec ewm de pandas et la trace avec la clôture dans Matplotlib ; 4.2 ajoute SMM, RSI et MACD.

2.1. Scénario : Suivre l'atelier jusqu'au projet EMA

  1. Cloner https://github.com/AlgoETS/Workshop1.git et lancer pip install -r requirements.txt.
  2. Démarrer jupyter notebook, ou ouvrir 1.0-basic/1.1_python_basic.ipynb dans Google Colab depuis le lien du README.
  3. Parcourir 1.0-basic, 2.0-api et 3.0-data dans l'ordre.
  4. Ouvrir 5.0-project/5.1_project_ema.ipynb et remplacer YOUR_API_KEY par une clé Financial Modeling Prep.
  5. Exécuter les cellules pour charger les cours d'AAPL dans un DataFrame, ajouter EMA_20 et tracer la clôture avec l'EMA 20 jours.

3. Démarrage

  • Ouvrir le premier notebook dans Colab : 1.1_python_basic.ipynb (lien du README).
  • Ou cloner le dépôt et lancer Jupyter en local ; les notebooks d’installation couvrent l’environnement.

La disponibilité des API, les clés et les versions de paquets peuvent avoir changé depuis l’atelier. Les notebooks sont du matériel pédagogique à examiner et adapter.

6. Limites et points à vérifier

  • L’exercice final relie une requête, des données tabulaires, des colonnes d’indicateurs et un graphique annoté. Il n’établit pas qu’un croisement soit rentable.
  • Vérifications utiles en classe : dates ordonnées, traitement volontaire des valeurs manquantes, pourquoi une EMA plus longue réagit plus lentement, et si toutes les courbes utilisent les mêmes observations.

11. Glossaire

Dépôt

Les fichiers source, la configuration et l’historique versionné d’un projet.

README

Le document d’entrée du dépôt, qui présente généralement son rôle et son installation.

Dépendance

Une bibliothèque, un outil ou un service nécessaire à la compilation ou à l’exécution d’un composant.

API

Une interface par laquelle des composants logiciels échangent des requêtes et des résultats. Une API n’utilise pas nécessairement HTTP.

HTTP

Un protocole de requête et réponse utilisé par les navigateurs et services web. Une requête comprend une méthode, un chemin, des en-têtes et parfois un corps.

Intégration continue

Des vérifications automatiques lors des changements de source, comme la compilation, les tests et l’analyse statique. Elles ne couvrent que ce qu’elles vérifient.

Mermaid

Un langage de diagrammes textuel. Les nœuds et liens décrivent un modèle ; le diagramme n’exécute pas le projet.
