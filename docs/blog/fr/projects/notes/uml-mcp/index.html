uml-mcp : D’un appel MCP à un diagramme

uml-mcp expose des outils de diagrammes aux clients MCP. Le client fournit une source et des options; le serveur valide la demande, l’oriente vers les services de rendu et retourne les résultats avec des liens d’édition.

Aperçu

Pourquoi il existe

Serveur phare Model Context Protocol (MCP) générant PlantUML, Mermaid et Kroki directement depuis des LLMs (Claude, Cursor, ChatGPT) sans dépendance locale.

Cas d’usage

Génération interactive de diagrammes d'architecture pour le pair programming avec IA et la documentation.

Lockfile and `requirements.txt`

CONTRIBUTING.md

uv.lock is the runtime source of truth for CI, Vercel, and release validation. Deploy/install paths export from the lockfile at runtime. Keep requirements.txt updated for users that still install with pip: Run this after changing runtime dependencies in pyproject.toml / uv.lock, then commit the updated requirements.txt. Transitive pins: Some packages are pinned only in [tool.uv] override-dependencies in pyproject.toml (they are not direct Poetry deps). Dependabot is configured for the uv ecosystem so PRs target uv.lock consistently. After merging a dependency PR, re-export requirements.txt if the lockfile changed so CI’s “export matches requirements.txt” step stays green.

  • a profile (local, docker or enterprise)
  • which features to turn on (each one is explained, with whether it applies live or needs a restart)

  1. validate the configuration

Health check (HTTP deployment)

docs/configuration.md

When running the FastAPI app (app.py) for HTTP deployment (e.g. Vercel, Docker, uvicorn), a health endpoint is available:

  • Endpoint: GET /health (no authentication required)
  • Response: {“status”: “healthy”, “modules_available”: true|false}
  • status: Always “healthy” when the server is up.
  • modules_available: Whether diagram backends (Kroki, PlantUML, etc.) could be loaded. Use /health for load balancers, Kubernetes or Docker liveness/readiness probes, Vercel checks, and similar monitoring whenever you run the FastAPI app (app.py). When running the MCP server via fastmcp run with HTTP transport only (no FastAPI app), the standalone server does not expose /health unless you add a custom route; use the FastAPI app if you need the health endpoint.

Fonctions et composants 2

Un point d’entrée sans sortie parasite
server.py délègue le démarrage à mcp_core.core.server. L’objet mcp est résolu à la demande par __getattr__, ce qui évite de construire le serveur ou d’écrire sur stdout lors d’un simple import. C’est important quand stdout transporte le protocole stdio.
Transport et rendu
Le serveur propose des parcours stdio et HTTP. Le cœur regroupe l’enregistrement des outils, la configuration et l’intégration Kroki. Le rendu reste une opération en aval: la couche MCP décrit les outils et transporte leurs entrées et résultats.

Contrat des outils MCP

Le service hébergé accepte les messages MCP JSON-RPC sur /mcp. tools/list retourne les schémas d’entrée et de sortie. Le client envoie tools/call avec le nom d’un outil et des arguments structurés.

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "generate_uml",
    "arguments": {
      "diagram_type": "mermaid",
      "code": "flowchart LR\n  Client --> Server",
      "output_format": "svg"
    }
  }
}

Réponse et erreurs

Lisez result.structuredContent : success, url, playground et output_format décrivent le rendu. En cas d’échec, inspectez error et error_detail; traitez séparément les erreurs de protocole MCP et isError au niveau de l’outil. Une réponse URL ne contient pas nécessairement les octets de l’image.
Utilisez validate_uml pour vérifier la syntaxe sans générer d’image. generate_uml_batch traite plusieurs éléments et retourne leurs résultats individuels. Envoyez uniquement du texte public au service hébergé; les URL de rendu peuvent encoder ce texte.
Authentification, limites et pagination

Ce point d’accès public a répondu à la génération documentaire sans en-tête Authorization. Cette observation ne définit pas l’authentification de tous les déploiements. tools/list n’annonçait aucun quota fixe. Le rendu retourne un résultat; la découverte du catalogue doit suivre la pagination MCP si le serveur retourne un curseur.

Glossaire

Dépôt

Les fichiers source, la configuration et l’historique versionné d’un projet.

README

Le document d’entrée du dépôt, qui présente généralement son rôle et son installation.

Dépendance

Une bibliothèque, un outil ou un service nécessaire à la compilation ou à l’exécution d’un composant.

HTTP

Un protocole de requête et réponse utilisé par les navigateurs et services web. Une requête comprend une méthode, un chemin, des en-têtes et parfois un corps.

Conteneur

Un environnement de processus isolé créé à partir d’une image. Les données persistantes nécessitent un stockage hors de son système de fichiers temporaire.

Port publié

Un port de l’hôte associé au port d’un service dans un conteneur. Sa publication peut rendre le service accessible hors du réseau des conteneurs.

Interface en ligne de commande

Une interface textuelle où les commandes et arguments choisissent les opérations. Les codes de retour permettent aux scripts de détecter un succès ou un échec.

Compilation

Les étapes qui transforment les sources et dépendances en programme exécutable ou en livrable distribuable.

MCP

Model Context Protocol : un protocole permettant à un client IA de découvrir et appeler des outils, et de lire les ressources d’un serveur.

Mermaid

Un langage de diagrammes textuel. Les nœuds et liens décrivent un modèle ; le diagramme n’exécute pas le projet.

GPU

Un processeur conçu pour les calculs parallèles, dont le rendu graphique et de nombreuses opérations numériques.
