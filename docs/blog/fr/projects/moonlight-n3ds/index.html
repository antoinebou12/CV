moonlight-N3DS

Dépôt · GPL-3.0

moonlight-N3DS est mon fork de zoeyjodon/moonlight-N3DS, client GameStream pour homebrew New 3DS. Les étoiles sur ce fork reflètent mes essais de port (encore faibles) ; installs et discussion communautaire sont en amont (~300★ sur zoeyjodon/moonlight-N3DS).

Article : Streaming portable et homebrew.

Notes

  • Cible New 3DS (pas OG 3DS) pour marge RAM/CPU
  • Client C++ issu de la lignée moonlight-embedded
  • Résolution et latence inférieures au streaming Switch

Démarrage

Voir le README sur la branche n3ds-main et le wiki amont : moonlight-embedded.
