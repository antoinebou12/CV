# PlantUMLApi

> Client Python pour générer des diagrammes via un serveur PlantUML.

- Page HTML: https://antoineboucher.info/CV/blog/fr/projects/plantumlapi/
- Langue: fr
- Traduction (en): https://antoineboucher.info/CV/blog/projects/plantumlapi/index.md
- Publié: 2021-09-06
- Mis à jour: 2021-09-06
- Auteur: Antoine Boucher (https://antoineboucher.info/CV/index-en.html)# PlantUMLApi

Interface Python vers un serveur **PlantUML** : génération de diagrammes UML et assimilés à partir d’un langage texte simple. Par défaut le client cible le serveur public PlantUML, mais il peut pointer vers n’importe quelle instance.

## Installation

```bash
pip install plantumlapi
```

ou depuis les sources :

```bash
pip install git+https://github.com/antoinebou12/plantumlapi
```

## Ligne de commande

```bash
plantumlapi --help
```

La référence complète des options et de l’API Python est en anglais dans le [dépôt](https://github.com/antoinebou12/plantumlapi).
