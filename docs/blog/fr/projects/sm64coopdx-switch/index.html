sm64coopdx-switch

Dépôt · Amont : coop-deluxe/sm64coopdx

sm64coopdx-switch porte coop-deluxe/sm64coopdx en homebrew Nintendo Switch. Ce fork suit mon travail de build Switch ; les étoiles sur ce dépôt sont distinctes de sm64coopdx amont (~1300★).

Article : Streaming portable et homebrew.

Légal

Il faut fournir sa propre ROM Super Mario 64 obtenue légalement. Le dépôt contient uniquement les sources du port et les scripts de build — aucun asset de jeu n’est distribué.

Pile

  • Port homebrew C depuis la base sm64coopdx decomp/coop
  • Co-op en ligne, support mods Lua (hérité de l’amont)

Démarrage

Voir le README pour la toolchain, l’emplacement ROM et la sortie build .nro.
