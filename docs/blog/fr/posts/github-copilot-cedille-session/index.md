## Pourquoi cette session

Les équipes étudiantes se demandaient si Copilot était de la triche, toléré en stage, ou utile pour les labs data. Avoir les vendeurs sur place coupe les rumeurs : voici l’outil, voici ce qui est produit aujourd’hui, voici les expériences sur **GitHub Next**.

## Démo live

| Sujet | Intérêt |
|-------|---------|
| **Copilot Chat** | Explications et refactors dans l’éditeur, pas seulement les complétions |
| **`/createNotebook`** | Amorcer un notebook Jupyter depuis le code du dépôt — énorme pour les cours et l’EDA |
| **[GitHub Next](https://githubnext.com)** | Bac à sable de features qui ne sortiront pas toutes en produit |

**`/createNotebook`** a fait réagir la salle : pointer Chat sur un module, demander un notebook qui importe et démonte — premier jet bien plus vite qu’un carnet vide. Pas magique : il faut encore vérifier chemins et versions.

## Retours perso

- **Accélérateur, pas auteur** — la review reste humaine au commit.
- **Notebooks au même niveau que le code** — les cursus data devraient enseigner Chat + notebooks ensemble.
- **Next ≠ produit** — GitHub Next pour prévisualiser sans parier sa thèse sur une API beta.
