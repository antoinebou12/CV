Créer un CV professionnel avec JSON Resume

La plupart des parcours passent par le web. JSON Resume permet de garder un resume.json structuré et de le rendre en HTML, PDF ou données intégrées à votre site. du même article.

1. Pourquoi du JSON ?

JSON Resume[1] est un schéma ouvert maintenu par la communauté. Fichier JSON simple : les thèmes et outils CLI changent la présentation sans réécrire le contenu. L’écosystème propose de nombreux styles—la grille ci-dessus montre des thèmes comme Elegant, Paper, Kendall et Flat.

Vous mettez à jour les données une fois, régénérez les exports, ou réutilisez le même fichier dans un générateur de site statique.

2. Sections principales

Un resume.json typique regroupe l’information en blocs prévisibles.

2.1. Basics

Nom, titre, courriel, site, résumé court, localisation, profils (LinkedIn, GitHub, etc.).

"basics": {
  "name": "Your Name",
  "label": "Job Title",
  "email": "your.email@example.com",
  "website": "https://yourwebsite.com",
  "summary": "A brief summary about yourself.",
  "location": {
    "city": "City",
    "region": "Region",
    "countryCode": "Country Code"
  },
  "profiles": [
    {
      "network": "LinkedIn",
      "username": "yourusername",
      "url": "https://www.linkedin.com/in/yourusername/"
    }
  ]
}

2.2. Expérience (work)

Entreprise, poste, dates, résumé du rôle.

"work": [
  {
    "name": "Company Name",
    "position": "Your Position",
    "startDate": "YYYY-MM-DD",
    "endDate": "YYYY-MM-DD",
    "summary": "Description of your role."
  }
]

2.3. Formation (education)

Établissement, domaine, type de diplôme, dates.

"education": [
  {
    "institution": "University Name",
    "area": "Field of Study",
    "studyType": "Degree Type",
    "startDate": "YYYY-MM-DD",
    "endDate": "YYYY-MM-DD"
  }
]

2.4. Compétences (skills)

Groupes avec niveau optionnel et mots-clés.

"skills": [
  {
    "name": "Programming",
    "level": "Intermediate",
    "keywords": ["Python", "JavaScript"]
  }
]

2.5. Projets (projects)

Portfolio ou projets significatifs avec dates, description et URL.

"projects": [
  {
    "name": "Project Name",
    "startDate": "YYYY-MM-DD",
    "endDate": "YYYY-MM-DD",
    "description": "Project description.",
    "url": "https://projecturl.com"
  }
]

3. Ligne de commande

Installation globale :

npm install -g resume-cli

Rédiger resume.json selon le schéma[2], choisir un thème, exporter :

resume export resume.html
resume export resume.pdf

Publication possible sur le registre JSON Resume[3] pour une page hébergée gratuite.

Même contenu, plusieurs sorties—pratique pour garder PDF et version web alignés.

4. Hugo et outils autour

Avec Hugo, le module hugo-mod-json-resume[4] mappe les sections JSON vers des modèles (y compris multilingue)—utile pour intégrer le CV dans un blog personnel.

Autres liens utiles :

  • Profile Studio[5] — prévisualisation en direct.
  • SkillSet[6] — visualisation D3 des compétences.
  • LinkedIn to JSON Resume[7] — amorcer resume.json depuis LinkedIn.

5. En bref

JSON Resume, c’est surtout de la discipline : une source de vérité, des thèmes pour la mise en page, puis CLI ou Hugo quand le PDF statique ne suffit plus. Pour un portfolio développeur, séparer contenu et présentation vieillit bien.
