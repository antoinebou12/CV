## Le lien avec mes projets

Le contenu sur le Model Context Protocol est le même protocole que celui derrière [uml-mcp](https://antoineboucher.info/CV/blog/fr/posts/uml-mcp/), le serveur MCP qui rend des diagrammes Mermaid, PlantUML et Kroki depuis un client de conversation. Le cours sur l'API couvre la forme des requêtes, l'usage d'outils et le streaming sur lesquels un client MCP s'appuie.
