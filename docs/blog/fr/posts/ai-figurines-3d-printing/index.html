Une image de jouet en 2D bien définie donne au modèle image→3D un point de départ utile. Suivez les étapes avec les diapositives et le workflow ComfyUI.

1. Pipeline (ordre)

  1. Photo de référence — profil ou face nette.
  2. Rendu chibi vinyle — ChatGPT, Midjourney ou ComfyUI (OmniGen2).
  3. Maillage — Hunyuan3D v2 (ComfyUI local ou outils en ligne).
  4. Impression — orientation, supports, résine ; îlots avec UVtools[1] si besoin.

2. Étape 1 — Jouet / chibi en 2D

Convert this image into a toy-style plastic figure. Keep features but simplify and smoothen as if molded in plastic.

Prompt chibi : figurine vinyle chibi, plastique lisse, fond blanc, un personnage, pose stable sur socle.

3. Étape 2 — ComfyUI (un graphe)

Télécharger : image_omnigen2_image_edit.json — Load dans ComfyUI (OmniGen2 + Hunyuan3D v2). Photo dans input/ : reference-photo.jpg.

ÉtapeRôle
AOmniGen2 + ReferenceLatent → PNG chibi
BHunyuan3D v2 → deux GLB (mesh/ComfyUI*.glb)

Prompts et graines dans le JSON. Nœuds Hunyuan3D-2 (GitHub[2]). Sur 8–12 Go VRAM, baisser octree_resolution ou num_chunks.

5. Quand utiliser quoi

SituationPiste
VRAM 8–12 Go, une photoComfyUI local (workflow fourni)
Test rapide sans GPUHi3DGen / Tripo3D en ligne
Figurine chibi déjà propreHunyuan3D ou RodinHD
Impression résine fineRéduire faces, vérifier îlots UVtools

6. Pièges

  • Photo de profil floue — le maillage fond les traits.
  • GLB énormes dans git — garder hors dépôt ; exporter depuis mesh/.
  • Sous-estimer les supports — cheveux et capes = îlots en slicer.

7. Aperçu maillage

Les GLB d’exemple (Hunyuan3D, RodinHD, Hyper3D, Hi3DGen) ne sont pas versionnés ici (20–75 Mo chacun). Utilisez l’aperçu des outils ou exportez depuis ComfyUI (mesh/ComfyUI*.glb).

8. Étape 4 — Réglages maillage

Ajuster faces, symétrie et remaillage avant export GLB/OBJ.

9. Étape 5 — Impression résine

Résine pour petites pièces ; incliner les porte-à-faux vers le plateau.

Vérifier les îlots avec le slicer ou UVtools[1].
