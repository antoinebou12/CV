GitHub Copilot session at Cédille (with GitHub & Arctiq)

Conference

Sep 6, 2022

At Cédille, we hosted a session with GitHub and Arctiq focused on GitHub Copilot and AI-assisted development. Highlights included Copilot Chat with /createNotebook for quick Jupyter notebooks from existing code, and pointers to GitHub Next experiments.

Thanks to speakers Thierry Madkaud and Eldrick Wega, and to everyone who joined.
