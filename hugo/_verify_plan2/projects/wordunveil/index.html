Development Setup WordsUnveil is a multilingual twist on the popular game Wordle, providing a fun and educational way to learn new languages. Built with advanced technologies for efficiency and a seamless gaming experience.

Getting Started

Development Setup

# Navigate to the WordsUnveil directory
cd WordsUnveil

# Install dependencies
yarn install

# Copy default environment variables
cp .env.default .env

# Run database migrations
yarn rw prisma migrate dev

# (Optional) Seed the database
yarn rw exec seed

# Start the development server
yarn rw dev

Docker-Compose Setup

# Start services with Docker
docker-compose up -d

PostgreSQL Database Setup

# Create PostgreSQL container named `db`
docker run --name=db -e POSTGRES_USER=admin -e POSTGRES_PASSWORD=admin -p '5432:5432' -d postgres

Deployment

Deploy the application to a bare metal server in production mode.

# Initial deployment
yarn rw deploy baremetal production --first-run
