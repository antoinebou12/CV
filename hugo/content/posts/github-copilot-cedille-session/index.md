At **Cédille**, we ran a session with **GitHub** and **Arctiq** on **Copilot** and the AI tooling around modern dev workflows. The part that stuck for me was **Copilot Chat** with **`/createNotebook`** — spin up a Jupyter notebook from code you already have, which is genuinely useful for data folks and anyone teaching labs. **[Version française]({{< ref "/posts/github-copilot-cedille-session/index.fr.md" >}})**.

<!--more-->

## What we saw

- **Copilot Chat** as a pair programmer in the editor, not just inline completions.
- **`/createNotebook`** to bootstrap notebooks from an existing repo — fast documentation and prototyping.
- **[GitHub Next](https://githubnext.com)** as the sandbox for experiments that might become product (worth bookmarking if you follow GitHub’s roadmap).
