# RawAnalyser

Outil Python pour l’analyse d’images RAW : détection de clipping noir/blanc, calcul gamma, planéité et vignettage (réf. Algolux), inspection des pixels Bayer.

## Prérequis

Python 2.7 ou 3 selon la branche du dépôt, avec notamment numpy, scipy, pyqt5, plotly, matplotlib, etc. (liste complète dans le README du projet).

## Usage

```bash
python rawanalyser.py --help
```

La documentation détaillée des options et workflows est en anglais sur [GitHub](https://github.com/antoinebou12/RawAnalyser).
